# Part 1 — Structures: Core Concepts

Study these concepts first.

### 1. Basic structure

```c
struct Student {
    char name[30];
    int age;
    float marks;
};
```

Creating a variable:

```c
struct Student s1;
```

Accessing members:

```c
s1.age
s1.marks
```

---

### 2. Pointer to structure

```c
struct Student *p = &s1;
```

You can access members using:

```c
(*p).age
```

or, more conveniently:

```c
p->age
```

Understand why:

```c
p->age
```

is equivalent to:

```c
(*p).age
```

---

### 3. Structure vs pointer to structure

Be able to explain the difference between:

```c
s1.age
```

and:

```c
p->age
```

# Part 5 — Dynamic Memory Allocation

Now begin `malloc()`.

Understand:

```c
int *p = malloc(5 * sizeof(int));
```

This requests enough memory for **5 integers**.

You should know:

```c
malloc()
free()
NULL
sizeof()
```

### Critical rule

Memory obtained through `malloc()` should eventually be released with:

```c
free(p);
```

Also understand why we check:

```c
if(p == NULL)
```

before using allocated memory.

## Q9. Dynamic memory debugging

What's wrong with this?

```c

    printf("Allocation failed");

free(p);
```

Consider what happens if allocation fails.

Correct the program.

# 🎯 Day 5 Success Criteria

By the end of today, you should be able to explain this chain:

```text
structure
   ↓
structure variable
   ↓
pointer to structure
   ↓
->
   ↓
dynamic allocation
   ↓
malloc()
   ↓
pointer to allocated memory
   ↓
free()
```

And these should be automatic:

```c
s.age
p->age
(*p).age
```

and:

```c
int *p = malloc(n * sizeof(int));
```

**Your biggest priority today is not memorizing `malloc()` syntax. It's understanding what the pointer represents and who owns the allocated memory.**
