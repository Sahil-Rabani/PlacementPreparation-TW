# 🚀 Week 5 — Day 3

## Pointers + Functions

This is where pointers become genuinely useful.

**Time: ~2 hours 45 minutes**

### Part 1 — Theory

Understand:

### Pass by Value

```c
void change(int x)
{
    x = 50;
}
```

Calling:

```c
int a = 10;
change(a);
```

does **not** change `a`.

---

### Using a Pointer

```c
void change(int *x)
{
    *x = 50;
}
```

Calling:

```c
change(&a);
```

changes the original variable.

Think:

```text
a
│
└── address ──→ pointer parameter
                    │
                    ↓
                   *x
                    │
                    ↓
                  a's value
```

# 🧠 Dry Run

Predict:

```c
void change(int *p)
{
    *p = *p + 10;
}

int main()
{
    int x = 20;

    change(&x);

    printf("%d", x);
}
```

Then explain the exact sequence:

```text
&x
 ↓
p
 ↓
*p
 ↓
x
```

# 🐞 Debugging

Find the problem:

```c
void swap(int *a, int *b)
{
    int *temp = a;
    a = b;
    b = temp;
}
```

Does this actually swap the **values**?

If not, explain what it swaps.

Then correct it.
