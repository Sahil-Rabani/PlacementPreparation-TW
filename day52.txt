## Q1 — The basic model

Explain in your own words:

```c
int x = 10;
```

versus:

```c
int *p = malloc(sizeof(int));
```

Answer:

1. What does `x` represent?
2. What does `p` represent?
3. Where is the actual integer stored in the second example?
4. What does `*p` mean?

# Q7 — Out-of-bounds memory

Find the error:

```c
int *p = malloc(5 * sizeof(int));

for(int i = 0; i <= 5; i++)
{
    p[i] = i * 10;
}

free(p);
```

Answer:

1. How many integers were allocated?
2. Valid indexes?
3. Which iteration is invalid?
4. Correct the loop.

---

# Q8 — Use-after-free

```c
int *p = malloc(3 * sizeof(int));

p[0] = 10;
p[1] = 20;
p[2] = 30;

free(p);

printf("%d", p[1]);
```

Answer:

* Is this valid?
* What type of problem is this?
* How should the program be corrected?
