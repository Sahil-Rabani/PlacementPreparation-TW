# 🐞 Debugging

Find every problem:

```c
int arr[3][3];

for(int i = 0; i <= 3; i++)
{
    for(int j = 0; j <= 3; j++)
    {
        scanf("%d", &arr[i][j]);
    }
}
```

Explain:

1. Which indexes are invalid?
2. What is the correct condition?
3. Why is this dangerous?
4. What type of bug is this?

# 🎤 Interview — 15 min

1. Why is a 2D array actually stored in **contiguous memory** in C?
2. What is the difference between `arr[i][j]` and `arr[j][i]`?
3. What is the time complexity of matrix addition for an `n × n` matrix?
4. Why does matrix multiplication require **three loops**?
5. What is row-major order?

### Important

**Day 5 is not a race.** Matrix multiplication is the first genuinely more algorithmic problem here. If you don't understand the three-loop structure, don't memorize it—work it out.
