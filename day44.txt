# 🧠 Part 1 — Memory & Addresses

### 30 minutes

Before writing pointer code, understand this model.

Suppose:

```c
int x = 10;
```

Imagine:

```text
Memory Address       Value
---------------------------
1000                 10
```

The variable `x` has:

* a **value** → `10`
* an **address** → `1000`

Now:

```c
printf("%d", x);
```

prints the **value**.

While:

```c
printf("%p", (void*)&x);
```

prints the **address**.

---

## Learn these two operators

### `&` — Address-of operator

```c
&x
```

means:

> "Give me the memory address of x."

### `*` — Dereference operator

If:

```c
int *p = &x;
```

then:

```c
*p
```

means:

> "Give me the value stored at the address contained in p."

Think:

```text
        x
        │
        │ value = 10
        ↓
Address 1000

p = 1000
│
└──────→ x

*p = 10
```

This relationship is the **most important thing today**.

as:

```text

│

p
│
└── contains the address of x
```
