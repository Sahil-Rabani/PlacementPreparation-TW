### Part 2 — 30 min: Understand the Algorithm

Before coding, write in English:

> How would I calculate one element `C[i][j]`?

You should arrive at:

```text
Take row i from A
+
Take column j from B
+
Multiply corresponding values
+
Add them
```

Then explain what `k` represents.


### Q5 ⭐

Check whether a matrix is **symmetric**.

A matrix is symmetric when:

```text
A[i][j] == A[j][i]
```

Example:

```text
1 2 3
2 4 5
3 5 6
```

is symmetric.

```text

```

but think carefully about **which elements you should swap**.
