# 🧠 Part 4 — Memory Allocation

First learn these four functions:

```text

```

You should understand the purpose of each rather than memorizing definitions.

---

## Q23 — Concept

Explain the difference between:

```c
int arr[10];
```

and:

```c
int *arr = malloc(10 * sizeof(int));
```

Focus on:

* where the memory comes from
* whether the size is fixed at declaration
* what happens when the memory is no longer needed

---

## Q24 — Predict / Explain

```c
int *p = malloc(5 * sizeof(int));

if(p == NULL)
{
    printf("Failed");
}
else
{
    for(int i = 0; i < 5; i++)
        p[i] = i * 10;

    printf("%d", p[3]);

    free(p);
}
```

Answer:

1. What is printed if allocation succeeds?
2. What does `p[3]` contain?
3. Why is `free(p)` required?
