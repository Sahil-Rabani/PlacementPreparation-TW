# 🚀 Week 5 — Day 4

## **Pointers + Strings + Pointer-to-Pointer**

Today is about moving from integer arrays to **character arrays/strings using pointers**, then introducing `int **`.

**Target time: 2–3 hours.**
Difficulty: **Medium → Hard**
Focus: **understanding, not memorizing code.**

---

# Part 1 — Theory & Concepts

Before coding, understand these:

### 1. String pointer traversal

Given:

```c
char str[] = "Thoughtworks";
char *p = str;
```

Understand:

```c
*p
*(p+1)
*(p+2)
```

and why:

```c
while(*p != '\0')
```

can traverse a string.

---

### 2. Two pointers on a string

Understand how:

```c
char *left = str;
char *right = str + strlen(str) - 1;
```

can be used to reverse a string.

---

### 3. Pointer-to-pointer

Understand:

```c
int x = 10;
int *p = &x;
int **q = &p;
```

Draw this mentally:

```text
q
↓
p
↓
x
10
```

Be able to explain:

```c
q
*q
**q
```

## Q5. Implement `strcmp()` properly

Write:

```c

```

It should behave like normal `strcmp()`:

* Return `0` if strings are equal.
* Return a negative value if `s1 < s2`.
* Return a positive value if `s1 > s2`.

Test:

```text

"apple", "banana"
"cat", "car"
```

**Important:** Don't simply return `1` or `0`. I want the actual lexicographical comparison logic.

# Part 3 — Pointer-to-Pointer

## Q7. Predict the output

Don't run it first. Dry-run it.

```c
#include <stdio.h>

int main()
{
    int x = 10;

    int *p = &x;
    int **q = &p;

    **q = 50;

    printf("%d", x);

    return 0;
}
```

Answer:

1. What does `p` contain?
2. What does `q` contain?
3. What does `*p` give?
4. What does `*q` give?
5. What does `**q` give?
6. Final output?

---

## Q8. Modify a pointer using `int **`

Write:

```c
void changePointer(int **p, int *newAddress)
```

The function should make the pointer supplied by the caller point to `newAddress`.

Test with:

```c
int a = 10;
int b = 20;

int *p = &a;

changePointer(&p, &b);

printf("%d", *p);
```

Expected output:

```text
20
```

### You must understand why this requires `int **` rather than `int *`.

# Part 4 — Debugging

## Q9. Find and fix the bug

```c
#include <stdio.h>

void change(int *p)
{
    p = NULL;
}

int main()
{
    int x = 10;
    int *ptr = &x;

    change(ptr);

    if(ptr == NULL)
        printf("NULL");
    else
        printf("%d", *ptr);

    return 0;
}
```

Answer:

1. What is the output?
2. Why doesn't `ptr` become `NULL`?
3. Correct the program so that `change()` can actually make `ptr` become `NULL`.
4. Why does the corrected version require `int **`?

## Q18 — Syllogism

Statements:

* All engineers are problem-solvers.
* Some problem-solvers are musicians.
* No musician is careless.
* Some engineers are musicians.
