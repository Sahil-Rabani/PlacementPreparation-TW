### Q4. Loop tracing

```c
#include <stdio.h>

int main() {
    int i, sum = 0;

    for (i = 1; i <= 5; i++) {
        if (i == 3)
            continue;

        sum += i;
    }

    printf("%d", sum);

    return 0;
}
```

### Q5. Nested loops

```c
#include <stdio.h>

int main() {
    int i, j, count = 0;

    for (i = 1; i <= 3; i++) {
        for (j = 1; j <= i; j++) {
            count++;
        }
    }

    printf("%d", count);

    return 0;
}
```

### Q6. Switch fall-through

```c
#include <stdio.h>

int main() {

    switch (n) {

            printf("A");
        case 2:
            printf("B");
        case 3:
            printf("C");
            break;
        default:
            printf("D");
    }

    return 0;
}
```

# Section C — Write Complete C Programs
**Q14–Q16 | 12 marks | Suggested time: 15 minutes**

These three questions simulate the limited space available in a written programming test. Write concise, complete, syntactically correct C programs.

### Q14. Array rotation — 4 marks

Write a C program to rotate an array **right by 2 positions**.

Example:

```text
Input:
6
1 2 3 4 5 6

Output:
5 6 1 2 3 4
```

Requirements:
- Read `n` and the array elements.
- Use loops.
- Do not print a hardcoded answer.
- Assume `2 <= n <= 100`.

### Q15. Second-largest distinct element — 4 marks

Write a C program to find the **second-largest distinct element** in an array without sorting it.

Example:

```text
Input:
6
8 3 5 1 9 3

Output:
Second largest = 8
```

Requirements:
- Use a single traversal if possible.
- Handle duplicate values correctly.
- Assume the array contains at least two distinct values.

### Q16. String analysis — 4 marks

Write a C program to count the vowels and consonants in a line of text.

Example:

```text
Input:
Hello World

Output:
Vowels = 3
Consonants = 7
```

Requirements:
- Use `fgets()` so spaces are accepted.
- Count only alphabetic characters.
- Ignore spaces, digits, punctuation, and the newline.
- Treat uppercase and lowercase vowels equally.
