## Part B — C Concepts / Debugging

### Q6
What is wrong with this code?

```c
int *p = malloc(5 * sizeof(int));

if (p == NULL)
    printf("Failed");

p[0] = 10;
```

Give the **precise issue**.

### Q7
What is the difference between:

```c
free(p);
```

and

```c
p = NULL;
```

### Q8
What is the output/error behavior?

```c
char str[20] = "HELLO";

printf("%d %d", sizeof(str), strlen(str));
```

Also mention the required header.

### Q9
Identify the bug:

```c
int *p = malloc(5 * sizeof(int));

free(p);

printf("%d", *p);
```

Name the exact type of error/undefined behavior.

## Part G — Final STEP Traps

### Q24 — Trace Carefully

```c
int x = 2;

for (int i = 1; i <= 3; i++) {
    x += i;

    if (x % 2 == 0)
        x /= 2;
    else
        x += 2;
}

printf("%d", x);
```

Give the **final value of x**.

---

### Q25 — Array + Pointer

```c
int arr[] = {10, 20, 30, 40, 50};
int *p = arr + 1;

printf("%d ", *p);
p++;
printf("%d ", *p + 5);
printf("%d", p - arr);
```

Give the exact output.
