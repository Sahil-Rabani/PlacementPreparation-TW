# Session 1 (45 Minutes)

## Theory

Study the following concepts.

### 1. What is a String?

Understand:

* Difference between a character and a string.
* Why strings end with the null character (`'\0'`).
* Memory representation of strings.

Example:

```c
char name[] = "Hello";
```

Memory layout:

```text
+-----+-----+-----+-----+-----+------+
| H   | e   | l   | l   | o   | '\0' |
+-----+-----+-----+-----+-----+------+
```

---

### 2. Ways to Declare Strings

Study all four:

```c
char name[] = "Hello";
```

```c
char name[10] = "Hello";
```

```c
char name[] = {'H','e','l','l','o','\0'};
```

```c
char name[20];
```

Know the difference between them.

---

### 3. Input Methods

Study:

```c
scanf("%s", str);
```

vs

```c
fgets(str, sizeof(str), stdin);
```

Questions to answer:

* Which reads spaces?
* Which is safer?
* Why?

---

### 4. Character Arrays vs Integer Arrays

Understand:

* Storage
* Traversal
* Null terminator
* Printing
