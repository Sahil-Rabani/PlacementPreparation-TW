# Section F — Memory Allocation

### Q23. Dynamic Memory

Answer the following:

```c
int *p = malloc(5 * sizeof(int));

if(p == NULL)
    return 1;

p[0] = 10;
p[1] = 20;

free(p);
p = NULL;
```

Explain:

1. What does `malloc()` do?
2. What does `free(p)` do?
3. What does `p = NULL` do?
4. Why is setting `p = NULL` after `free(p)` useful?
